# Panduan pengguna — status draft planning

Panduan final dibuat dari aplikasi yang telah diuji. Baseline alur operator: masuk online pertama, pilih kandang penugasan, isi total pakan/telur tanggal farm, simpan, periksa status kirim, buat temuan dan kerjakan tugas. “Tersimpan di perangkat” berbeda dari “Diterima sistem”. Jangan menghapus data app sebelum antrean terkirim.

Pengelola menyiapkan kandang/kelompok/stok/pengguna/tugas, meninjau missing/temuan, merevisi accepted dengan alasan dan mengekspor accepted report. Tidak ada diagnosis atau laba otomatis. Flow lengkap: ../flows-and-screens.md; prototype fiktif dan belum dapat menjadi panduan operasional farm.
